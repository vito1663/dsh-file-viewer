# dsh-file-viewer

**一句话：在 dsh 的网页界面里，直接浏览和查看"跑 dsh 的那台机器"上的文件和目录。**

## 解决了哪两个痛点？

**痛点一：看不到服务器上的文件。**
dsh 跑在服务器上，但你在网页里没有任何入口能直接查看服务器上的文件——想看内容只能 SSH 上去。

**痛点二：远程使用时，点会话里的文件路径，会去你当前操作的设备上找。**
dsh 装在服务器（或远程电脑）上，而你在另一台设备上操作。点击会话里的文件路径时，dsh 默认文件存在于"当前这台设备"上，于是到你的本地设备上查找——你本地当然没有服务器上的文件，结果必然"找不到"。

装上这个插件后：你用自己的电脑或手机打开 dsh 网页 → 点「文件」标签 → 输入路径或浏览目录 → 服务器上的文件直接在网页里渲染出来，不再依赖"文件在哪台设备上"。

> 插件装在你自己电脑的 dsh 上同样能用——此时看的就是你自己电脑的文件。

## 它能干什么

- **浏览目录**：输入一个目录路径（比如 `/srv/share`），立刻列出里面的子目录和文件；点子目录进入、点文件打开；支持"上一级"和路径面包屑跳转。
- **打开文件**：输入一个文件路径，自动识别类型并渲染。认识这些格式：

| 格式 | 渲染方式 |
|---|---|
| Markdown | 标题 / 列表 / 表格 / 引用 / 代码块 / 行内样式 |
| HTML / SVG | 沙箱 iframe（禁止脚本，安全） |
| 图片（PNG/JPG/GIF/WebP） | 直接显示 |
| PDF | 内嵌显示，也可以"新窗口打开" |
| Word（.docx） | 自动转成网页显示（标题/表格/图片都在） |
| Word（.doc 旧格式） | 自动转成文本显示 |
| JSON | 格式化显示 |
| CSV / TSV | 表格显示 |
| 任意文本 / 代码 / 日志 | 等宽字体显示 |

> 识别靠"文件内容魔数"优先，扩展名骗不了它。

- **对话联动**：在对话里点产物文件或文件路径，会自动跳到「文件」标签页打开（无头服务器需装一个兼容小补丁，见下文）。

## 安装

要求 Node >= 22，且已有 dsh web 环境。

```sh
# 在你的 dsh profile 里安装（比如 web profile）
dsh plugin --profile web add github:vito1663/dsh-file-viewer -w
```

装完**在插件目录里**再装一个可选依赖（用来把 Word 转成网页）：

```sh
cd <插件目录>       # 通常是 ~/.dsh/local-plugins/dsh-file-viewer
npm install mammoth
```

- 想支持旧版 `.doc` 文件，服务器上再装个 `antiword`：`apt install antiword`（Debian/Ubuntu）。
- 这两个都是**可选的**：不装的话，打开 Word 文件会提示错误，其他功能不受影响。

最后重启 dsh web（systemd 托管的话：`sudo systemctl restart dsh-web`）。

## 使用

1. 打开 dsh 网页，进入任意会话。
2. 点顶部的**「文件」**标签（在「对话」「轨迹」后面）。
3. 输入服务器上的绝对路径，回车或点「打开」：
   - 目录 → 显示内容列表，可以一层层点进去；
   - 文件 → 自动渲染。

首次点「文件」标签会默认显示当前工作区目录；之后再看过的文件会记住，切回来直接显示。

## 安全

- **只读**：只看不写，绝不执行任何东西。
- **限大小**：普通文件 ≤ 6 MB，Word ≤ 30 MB。
- **敏感路径拒绝**：`/etc`、`/proc`、`.ssh`、`.git`、`settings.yaml`、`.env`、`.npmrc` 等一律不给看，目录列表里也直接隐藏。
- **重要**：这个插件通道只做"防 DNS 重绑定"防护，**不是登录认证**。请确保你的 dsh 部署本身有认证（访问密码 / 反向代理鉴权），别裸奔在公网上。

## 无头服务器兼容补丁（推荐装）

无头服务器上，dsh 自带的"在对话里打开文件"动作会走 `xdg-open` 而失败。这个仓库附带一个小脚本，把它改成跳到「文件」标签页：

```sh
node scripts/patch-conversation-openfile.mjs
```

- 幂等：重复运行没副作用；dsh 升级覆盖了文件后，重跑一次即可。
- 没装插件时这个补丁不产生任何效果，放心。

## 开发

```sh
npm install                          # 装 mammoth
node scripts/build-client.mjs        # client.client.src.js → client/client.js
npm test                             # 宿主契约测试
```

`client/client.js` 由 `client/client.src.js` 生成——改源码后重新构建。
